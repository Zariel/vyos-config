# Network design

The canonical [network design and numbering plan](https://github.com/zariel/home-ops/blob/main/docs/network-design.md)
lives in `home-ops/docs/network-design.md`. It records deployed assignments,
reservations, routing ownership, the path symmetry requirement, planned loopback
BGP peering and dual-homing, and the intended migration of allocations to NetBox.
